# BAI 02 - BT08: TRAVELLING APP

## 1. Thông tin dự án

- **Tên ứng dụng:** TravellingApp
- **Môn học:** React Native
- **Sinh viên:** Nguyễn Minh Khang
- **Trường:** Trường Cao đẳng Kỹ thuật Công nghệ Nha Trang
- **Nền tảng:** React Native - Expo SDK 58.0.0
- **Công cụ phát triển:** Expo Snack

## 2. Giới thiệu

TravellingApp là ứng dụng du lịch giúp người dùng khám phá các địa điểm nổi tiếng tại Việt Nam, xem thông tin địa điểm và lưu lại những nơi yêu thích.

Ứng dụng có giao diện đơn giản, dễ sử dụng và được xây dựng bằng React Native.

## 3. Chức năng chính

- Hiển thị danh sách địa điểm du lịch.
- Phân loại địa điểm theo danh mục.
- Thêm và xóa địa điểm yêu thích.
- Xem danh sách địa điểm đã yêu thích.
- Hiển thị thông tin cá nhân.
- Chuyển đổi giữa Trang chủ, Yêu thích và Cá nhân.

## 4. Cấu trúc thư mục

```text
TravellingApp/
├── App.js
├── package.json
└── components/
    ├── TravelHeader.js
    ├── DestinationCard.js
    ├── CategoryList.js
    ├── FavoriteCard.js
    └── ProfileInfo.js
```

## 5. Các Component

| Component | Chức năng |
|---|---|
| TravelHeader | Hiển thị tiêu đề ứng dụng |
| DestinationCard | Hiển thị thông tin địa điểm |
| CategoryList | Hiển thị danh mục du lịch |
| FavoriteCard | Hiển thị địa điểm yêu thích |
| ProfileInfo | Hiển thị thông tin cá nhân |
